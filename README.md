# Лабораторная работа 1. Первые программы на Python

## Запуск программ
Каждая программа запускается через терминал[cite: 1]:
- python hello.py
- python profile.py
- python workload.py
- python debug.py
- python swap.py
- python variant.py

---

## Проверки и результаты

### 1. Карточка студента (profile.py)
- Входные данные: возраст 17, подготовка 10.5 ч/неделю[cite: 1].
- Ожидаемый и фактический результат: возраст через 4 года составляет 21, подготовка за 4 недели равна 42.00 ч, в день - 1.50 ч[cite: 1].
- Дополнительная проверка: при 0 часов подготовки результат равен 0.00[cite: 1].

### 2. Учебная нагрузка (workload.py)
- Входные данные: 3 занятия по 90 минут, 2 занятия по 45 минут, доступно 10 часов[cite: 1].
- Ожидаемый и фактический результат: 270 и 90 минут, общая нагрузка 360 минут или 6.00 часов, остаток свободного времени 4.00 часа, нагрузка за 4 недели 24.00 часа[cite: 1].
- Дополнительная проверка: отсутствие занятий по обоим предметам обрабатывается корректно[cite: 1].

### 3. Поиск и исправление ошибок (debug.py)
- Фрагмент А: исправлено соединение строк на арифметическое сложение, результат равен 5[cite: 1].
- Фрагмент Б: исправлен тип данных через int(), при вводе 17 возраст через год равен 18[cite: 1].
- Фрагмент В: исправлен приоритет операций с помощью скобок, среднее арифметическое равно 7.0[cite: 1].

### 4. Обмен значениями (swap.py)
- Входные данные: А-101 и Б-202[cite: 1].
- Ожидаемый и фактический результат: значения успешно поменялись местами (первая аудитория стала Б-202, вторая - А-101); одинаковые названия остаются одинаковыми[cite: 1].

### 5. Индивидуальный вариант 1: Канцелярия (variant.py)
- Входные данные: тетради 3 шт. по 12.50, ручки 2 шт. по 20.00, доставка 10.00, внесено 100.00[cite: 1].
- Ожидаемый и фактический результат: стоимости 37.50 и 40.00, товары 77.50, всего к оплате 87.50, количество 5, сдача 12.50[cite: 1].
- Дополнительные проверки: нулевое количество одной позиции, нулевая доставка, точная оплата без сдачи и названия из нескольких слов прошли успешно[cite: 1].
